## Supplement Tracker

A simple Java application to manage your daily supplements.
It allows you to track supplement name, dose and time of the day.

## Project Structure
- 'data' - class for supplement data, (e.g. 'Supplement.java'),
- 'app' - application logic: adding, sorting, filtering, etc. supplements,
- 'ui' - helper methods for displaying sets and user input,
- 'enums' - enum types (e.g. 'TimeOfDay.java'),
- 'main' - entry point.

## Features
- Track supplements by name, dose and time of the day,
- Avoid duplicates using Set
- Sort and display supplements by different criteria,
- Simple console menu for user interaction.
